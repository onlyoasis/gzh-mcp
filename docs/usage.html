MCP Server 使用手册

把草稿发布、素材、统计、用户标签、菜单、评论、群发、定向推送与常用基础接口 封装成标准 MCP 工具，供本机 MCP 客户端（Claude Code、Codex CLI 等）调用。 本手册对应仓库 README 与 docs/ 的现行版本。

01

不做排版

create_draft 接受已排版的微信 HTML，Markdown 转换由调用方完成。

02

无本地状态

不持久化业务数据；仅下载工具按指定路径写文件，且拒绝覆盖已有文件。

03

凭据零落盘

AppSecret 只从环境变量注入；secret 与 access_token 全链路脱敏。

04

错误详情可见

微信 errcode/errmsg、本地拒绝理由完整返回给调用方，不被 SDK 掩码。

01

快速开始

从零到能调用第一个工具，需要完成依赖安装与客户端注册两步。

环境要求

  • Python 3.12+ 与 uv
  • 公众号 AppID / AppSecret（公众平台 → 设置与开发 → 基本配置）
  • 出口 IP 已加入公众号 IP 白名单，否则报 40164

发布权限说明

  • freepublish/* 仅对已认证账号开放
  • 个人主体 / 未认证账号通常返回 48001
  • 草稿与素材接口不受此限制

安装与自检

  • git clone 后进入目录执行 uv sync
  • uv run pytest 验证安装（测试全 mock，不真实调微信）
安装
# 克隆并安装依赖
git clone https://github.com/onlyoasis/gzh-mcp.git
cd gzh-mcp
uv sync
uv run pytest   # 验证安装：195 个测试应全部通过
MCP 客户端配置（stdio JSON）
{
  "mcpServers": {
    "gzh": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/gzh-mcp", "gzh-mcp"],
      "env": {
        "WECHAT_APPID": "<你的 AppID>",
        "WECHAT_SECRET": "<你的 AppSecret>",
        "GZH_MCP_PROXY": "http://127.0.0.1:2080",
        "GZH_MCP_ALLOW_PUBLISH": "0",
        "GZH_MCP_ALLOW_MASS_SEND": "0"
      }
    }
  }
}
Claude Code 命令行注册
claude mcp add gzh -s user \
  -e WECHAT_APPID=<你的 AppID> \
  -e WECHAT_SECRET=<你的 AppSecret> \
  -- uv run --directory /path/to/gzh-mcp gzh-mcp
环境变量必填说明
WECHAT_APPID是公众号 AppID
WECHAT_SECRET是AppSecret，仅经环境变量注入，不落任何文件
GZH_MCP_PROXY否显式 HTTP(S) 代理；server 不继承宿主代理环境，适用于固定出口 IP 白名单
GZH_MCP_ALLOW_PUBLISH否1/true 注册 publish_draft；其余值一律视为关闭
GZH_MCP_ALLOW_MASS_SEND否1/true 注册 4 个群发发送 / 预览工具；其余值一律视为关闭
注意：MCP 客户端会缓存工具列表。修改闸门环境变量后需要重启客户端， 新注册或移除的工具才会生效。
02

安全模型

发布、群发、定向推送和删除会改变外部状态。server 通过「注册闸门 + 调用闸门」双层控制， 校验失败时不发出任何 HTTP 请求。

1 · 注册闸门（安装时）

GZH_MCP_ALLOW_PUBLISH 严格匹配 1 或小写 true（0/false/TRUE/空串均不生效）时， publish_draft 才会出现在工具列表。

2 · 确认闸门（每次调用）

publish_draft 必须显式传 confirm=true， 否则直接拒绝，不发出任何 HTTP 请求。

3 · 群发双闸门

GZH_MCP_ALLOW_MASS_SEND 严格为 1/true 时 4 个群发工具才注册；其中三个发送工具还必须传非空 clientmsgid 与 confirm=true。

4 · 逐次确认

删除类工具（草稿 / 已发布文章 / 素材 / 标签 / 菜单 / 群发消息）以及客服、模板、 订阅通知发送工具，每次调用都必须显式传 confirm=true。

其他安全行为说明
脱敏WECHAT_SECRET 与 access_token 不出现在错误信息、日志或 stdout；stdout 只承载 MCP JSON-RPC，诊断写 stderr
非幂等不重试创建草稿、发布、群发与定向推送遇网络传输错误返回「状态不确定」错误，禁止自动重试，防止重复建稿、重复提交
只读有限重试只读接口遇传输错误、HTTP 5xx 或微信 errcode=-1 最多退避重试一次
草稿前置拦截非微信域正文图 URL、<script>、空标题/正文在本地拒绝；图片按文件魔数校验真实格式
创建后回读验证自动核对标题、图片数、正文长度；微信清洗了内容时返回 verified=false + 差异详情，不静默成功
发布结果可核对带脱敏 appid 前缀、草稿标题、media_id，便于调用方核对目标账号

04

典型工作流

发布一篇已排版的 HTML 文章的完整链路；开启自动发布后追加第 6–7 步。

01 check_credentials 确认凭据与 IP 白名单正常
02 upload_cover_image(cover.png) 得到 thumb_media_id（封面永久素材）
03 upload_content_image(a.png) … 得到微信图片 URL，替换正文 HTML 中的 src
04 create_draft([{title, content, thumb_media_id, digest}]) 创建草稿，返回 media_id + verified
05 人工在公众号后台复核草稿，发布 默认路径：发布动作由人工完成
06 publish_draft(media_id, confirm=true) 需 GZH_MCP_ALLOW_PUBLISH=1；提交发布，返回 publish_id
07 get_publish_status(publish_id) 轮询异步发布状态，直至终态
状态码含义
0成功
1发布中
2原创失败
3常规失败
4审核不通过
5 / 6成功后被删除 / 封禁
05

正文 HTML 规则

create_draft / update_draft 的 content 字段接受已排版的微信 HTML。本地只强制以下三条， 失败不发任何 HTTP 请求，错误信息直达调用方。

1

content 必须是非空字符串

空串或缺失会以「content 必须是非空字符串」拒绝。

2

禁止 <script> 标签

大小写不敏感，<SCRIPT> 同样拒绝；微信保存时也会移除 JS。

3

正文图片必须是微信域名

每个 <img> 的 src（或 data-src）必须是 http(s) 协议且域名为 mmbiz.qpic.cn / mmbiz.qlogo.cn；相对路径与外链一律拒绝——微信本来就会过滤外链图，本地先报错可避免建稿成功但图全丢。

4

正文图：先上传、后引用

upload_content_image 只接受 JPEG / PNG（按文件魔数判定，不看扩展名），严格小于 1MB； 返回的微信 URL 填进 src。封面不在 HTML 里，走 upload_cover_image 的 thumb_media_id（JPEG/PNG/GIF/BMP，≤10MB）。

5

长度交由平台判定

标题只校验非空（真机实测 39 字符可保存）；正文不做本地长度限制（实测 24061 字符可保存）； 摘要 digest 保留 ≤120 字符的保守限制（官方上限 128）。

6

创建后自动回读验证

核对文章数、标题、图片数、正文长度（缩水超 5% 报警），不一致返回 verified=false + verification_errors，不静默成功。微信会把 src 归一化为 data-src（懒加载），两者都计入图片数，属正常现象。

7

图片帖（article_type=newspic）

content 只是说明文字；图片由 image_info.image_list[].image_media_id 提供，1–20 个非空永久素材 ID，回读时核对图片数。

通过本地校验形状的最小 HTML
<section style="margin: 0; padding: 16px;">
  <p style="font-size: 15px; line-height: 1.75;">正文第一段。</p>
  <p style="font-size: 15px; line-height: 1.75;">
    <img src="https://mmbiz.qpic.cn/mmbiz_png/xxxx.png" style="width: 100%;">
  </p>
</section>
常见错误信息原因与处理
content 不能包含 script 标签HTML 含 <script>（含大小写变体），移除脚本
content 含非微信正文图片 URL: …src 非微信域或相对路径；先 upload_content_image 再替换 URL
图片真实格式必须是 JPEG 或 PNG正文图魔数不符，转换格式
正文图片必须严格小于 1MB正文图 ≥ 1MiB，压缩图片
digest 不能超过 120 字符摘要超长，截短
第 N 篇图片数量不一致（verified=false）微信过滤了图片，查看差异详情并修正
第 N 篇正文长度缩水超过 5%微信清洗了部分内容，后台复核或 update_draft 修正
06

已知约定与限制

状态与对账

  • server 无本地状态：media_id → publish_id 映射由调用方记录
  • 事后对账用 list_published
  • 发布为异步语义：拿到 publish_id 不等于发布成功，以 get_publish_status 终态为准

文件路径边界

  • file_path 指 MCP server 所在主机的本地文件
  • server 与客户端须同机，不支持远程部署
  • get_material / download_temp_media 的 save_path 自动建父目录，目标文件存在时拒绝覆盖

媒体限制

  • 正文图：jpg/png 且严格小于 1MB
  • 封面：jpg/png/gif/bmp，≤10MB
  • 图片按文件魔数校验真实格式，扩展名伪装无效

开发与验证

  • uv sync 安装依赖；uv run pytest 全量测试
  • uv run gzh-mcp 本地启动（stdio）
  • 测试全部 mock，不真实调用微信；回归测试须先红灯验证
